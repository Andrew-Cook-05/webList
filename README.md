# webList

webList is a website that allows you to display and adjust data from an API.

## Project Status
Right now, the project is a simple counter app that I made to familiarize myself with TypeScript + React + CSS formatting options.

I also have the beginnings of the home page for the actual webList project, although it doesn't have much on there. There is a "Log in with Google" button that takes you to a login page, but that is all. It is also not formatted well yet.

## How to Run

To run, use `npm run dev` in the terminal.
